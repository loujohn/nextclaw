# v0.3.0-chat-timeline-display

## 迭代完成说明

- 重构员工聊天页的 assistant 展示方式，将思考过程、工具调用、工具结果、过程内回复改为按顺序渲染的时间线节点。
- 保留最终回答的独立展示区，不再把过程信息和最终答案混在同一个折叠块里。
- 为流式聊天过程补充前端实时 timeline 节点，运行中即可看到过程更新，不必等到结束后再集中显示。
- 为聊天消息分组逻辑补充时间线模型测试，验证工具结果、过程回复与最终答案的分离行为。

## 测试/验证/验收方式

- 单元测试：`pnpm -C packages/nextclaw-digital-employee exec vitest run tests/chat-message-groups.test.ts`
- 编辑器问题检查：确认 `app/pages/employees/[id]/chat.vue`、`app/lib/chat-message-groups.ts`、`shared/ui-models.ts` 无新增错误。
- 补充静态校验：建议执行受影响文件的 ESLint 定向检查，确认模板与类型未引入回归。

## 发布/部署方式

- 本次仅涉及前端聊天展示，无数据库结构与服务端发布链路变更。
- 按常规前端发布流程构建并部署 `@nextclaw/digital-employee` 即可；migration 不适用。

## 用户/产品视角的验收步骤

1. 打开任一员工的聊天页并发送一条会触发思考与工具调用的问题。
2. 确认 assistant 回复区先出现“执行时间线”，并按顺序展示思考过程、工具调用、工具结果、过程内回复。
3. 确认每个时间线节点带有对应时间标签或至少具备明确顺序。
4. 确认最终回答单独显示在时间线下方，而不是混在过程节点里。
5. 刷新当前会话后再次查看历史消息，确认时间线与最终回答仍然分开展示。
