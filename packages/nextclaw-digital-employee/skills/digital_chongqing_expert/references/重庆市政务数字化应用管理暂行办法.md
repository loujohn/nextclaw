## 总则

### 立法目的
为规范政务数字化应用管理，提高应用建设质量和使用效益，推动数字重庆建设，根据相关法律法规，制定本办法。

### 适用范围
本办法适用于本市各级国家机关、事业单位和社会团体（以下统称应用单位）开展的政务数字化应用建设和管理活动。

### 基本原则
1. **统筹规划**：坚持全市统一规划，避免重复建设
2. **标准统一**：遵循统一的技术标准和数据规范
3. **共建共享**：推动应用共建、数据共享、能力复用
4. **安全可控**：确保应用安全和数据安全
5. **注重实效**：以提高政务服务效能为目标

## 管理体制

### 职责分工
1. **市大数据发展局**：负责全市政务数字化应用的统筹规划、标准制定、监督检查
2. **市级部门**：负责本部门、本系统应用的建设和管理
3. **区县大数据主管部门**：负责本区县政务数字化应用的统筹管理
4. **应用单位**：负责本单位应用的建设、使用和维护

### 管理体系
建立市、区县两级管理机制，形成上下联动、协同推进的工作格局。

## 应用立项

### 立项条件
1. 符合数字重庆建设总体规划和业务发展需要
2. 符合多跨协同要求，至少跨两个部门或跨两个层级
3. 具有明确的应用需求和预期目标
4. 有可行的技术方案和实施计划
5. 有稳定的资金来源和保障措施

### 审批流程
1. **需求论证**：应用单位开展需求调研和可行性分析
2. **方案编制**：编制应用建设方案和技术方案
3. **专家评审**：组织专家对方案进行评审
4. **部门审核**：相关部门对方案进行审核
5. **立项批复**：符合要求的，由大数据主管部门批复立项

## 应用开发

### 开发规范
1. **遵循统一架构**：基于"1361"整体架构进行开发
2. **使用统一平台**：基于一体化智能化公共数据平台开发
3. **遵循统一标准**：遵循统一的技术标准和数据规范
4. **确保安全可控**：符合网络安全和数据安全要求

### 技术标准
1. **架构设计**：采用微服务架构，支持灵活扩展
2. **接口规范**：遵循统一的接口规范和数据格式
3. **数据规范**：遵循统一的数据标准和元数据规范
4. **安全规范**：符合等级保护2.0要求和数据安全规范

## 应用验收

### 验收标准
1. **功能验收**：功能完整，满足需求
2. **性能验收**：性能达标，满足使用要求
3. **安全验收**：符合安全规范，通过安全检测
4. **数据验收**：数据完整、准确、规范
5. **文档验收**：文档齐全，符合规范

### 验收流程
1. **申请验收**：应用单位提交验收申请和相关材料
2. **材料审查**：大数据主管部门对验收材料进行审查
3. **专家验收**：组织专家对应用进行验收评审
4. **问题整改**：对验收中发现的问题进行整改
5. **验收通过**：符合要求的，出具验收通过意见

## 应用运维

### 运维要求
1. **7×24小时运行保障**：确保应用稳定运行
2. **数据备份**：定期进行数据备份，确保数据安全
3. **故障处理**：建立故障处理机制，及时处理故障
4. **性能监控**：对应用性能进行监控，及时发现和处理问题
5. **安全防护**：建立安全防护体系，确保应用安全

### 安全保障
1. **网络安全**：符合网络安全等级保护要求
2. **数据安全**：建立数据安全防护体系，保护数据安全
3. **应用安全**：定期进行安全检测和漏洞修复
4. **人员安全**：加强人员安全管理，防止内部风险

## 监督检查

### 检查机制
1. **定期检查**：大数据主管部门定期对应用建设和管理情况进行检查
2. **专项检查**：对重点应用进行专项检查
3. **随机抽查**：不定期对应用进行随机抽查
4. **问题通报**：对检查中发现的问题进行通报

### 责任追究
1. **责令整改**：对不符合要求的应用责令限期整改
2. **暂停使用**：对存在重大问题的应用暂停使用
3. **责任追究**：对违反本办法的单位和个人依法追究责任

## 附则

本办法自发布之日起施行。
