## 发展阶段全景

数字重庆建设自2023年启动以来，历经四个阶段，每个阶段都有明确的目标和成果：

```
2023.04.25 ──→ 2024.01.31 ──→ 2024.07.25 ──→ 2025.04.18
第一阶段         第二阶段         第三阶段         第四阶段
拉开大幕         形成重点能力     向基本能力深化   基本能力整体跃升
```

---

## 第一阶段：拉开以数字化变革推动重庆迈向现代化的大幕（2023.04.25 - 2024.01.31）

### 2023年4月25日 - 数字重庆建设会议（启动会）
**历史性时刻**：正式启动数字重庆建设

**核心定义**：
> 数字重庆建设，就是运用数字化技术、数字化思维和数字化认知，把数字化、一体化、现代化贯穿到党的领导和经济、政治、文化、社会、生态文明建设全过程各方面，以跨层级、跨地域、跨系统、跨部门、跨业务的高效协同为突破，以数字赋能为手段，以数据流整合决策流、执行流、业务流，推动各领域工作体系重构、业务流程再造、体制机制重塑，从整体上推动市域经济社会发展质量变革、效率变革、动力变革，推进市域治理体系和治理能力现代化。

**关键部署**：
- 围绕数字重庆"1361"整体构架作出全面部署
- 各级各部门闻令而动，组建专班，边学边干
- 合力推动数字重庆建设开好局、起好步

### 2023年7月27日推进会
**本质认知深化**：
数字重庆建设本质上是对发展、服务、治理能力的系统性变革重塑：
- **观念转变**：从传统管理 → 整体智治
- **方法转变**：从修修补补 → 系统重塑
- **机制转变**：从各自为政 → 多跨协同
- **手段转变**：从信息壁垒 → 通过数据流打通决策流、业务流、执行流
- **能力转变**：从宏观向微观、从定性向定量

### 2023年10月30日推进会
**战略定位**：
数字重庆建设是现代化新重庆建设必须跨越的重要关口，是实现超大城市治理全方位变革系统性重塑的**关键变量**。

## 第二阶段：形成重点能力向基本能力深化拓展（2024.01.31 - 2024.07.25）

### 2024年1月30日推进会
**改革维度定位**：
数字重庆建设是全面深化改革的重要维度，是为现代化新重庆增动力、添活力、防风险、促发展的全新探索实践。

### 2024年4月7日推进会
**战略地位确立**：
> 数字重庆建设是事关现代化新重庆建设的战略性、基础性和全局性工作。
> 超大城市治理现代化是新重庆建设牵一发动全身的重要任务，数字重庆建设是实现这一目标任务的有效路径。

**阶段目标**：
- 围绕"一年形成重点能力"目标
- 加快点上攻坚突破、面上整体推进
- 努力打造重点领域实用实战成果
- 各级各部门聚焦重大任务，集中攻坚
- 推动中心城区重点突破，带动其他区县实战能力提升

## 第三阶段：探索超大城市现代化治理新路子（2024.07.25 - 2025.04.18）

### 2024年7月25日推进会
**新阶段开启**：
> 数字重庆建设是积极探索超大城市现代化治理新路子的破题之道、实现路径，当前已进入基本能力建设新阶段。

**重大部署**：
- 把推进数字重庆建设与落实党的二十届三中全会对进一步全面深化改革的战略部署结合起来
- 打造部门单位核心业务日常工作履职数字化支撑能力
- 向国有企业、金融机构、高校、医院等企事业单位延伸拓展
- 全方位提升发展、服务、治理能力

### 2024年10月24日推进会
**工作要求**：
- 深入学习贯彻党的二十届三中全会精神
- 全面落实习近平总书记视察重庆重要讲话重要指示精神
- 牢牢把握目标任务，锚定关键时间节点
- 坚持急用先行，强化贯通实战
- 突出中心城区先行先试、探路领跑
- 全力推动数字重庆基本能力建设实现突破性进展
- 更好赋能推动高质量发展、创造高品质生活、实现高效能治理

**阶段评价**：
数字重庆建设按下"快进键"，进入了从量变到质变的新阶段。

**实战成效**：
- 各级各部门突出急用先行
- 点上巩固基础、面上拓展成势
- 加快打造数字重庆实用实战标志性成果

## 第四阶段：基本能力整体跃升新阶段（2025.04.18至今）

### 2025年1月9日推进会
**三级中心定位**：
> 三级治理中心是超大城市现代化治理的重要抓手载体，也是数字重庆基本能力建设的主轴。各方面和各级各部门企事业单位基本能力也都要通过三级治理中心来生成、来传递、来转化、来检验。

**数据归集要求**：
- 全市各部门各系统和国有企业、高校、医院等要落实主体责任
- 全量全时全程对接IRS系统编目、归集、治理、共享
- 做到应归集尽归集、能共享尽共享

### 2025年4月18日推进会 ⭐（最新）
**核心任务**：
围绕**8个关键指标**，强化分级分类分层评价，促进互学互促、比学赶超，乘势而上推动数字重庆基本能力建设全面跃升。

#### 八大关键指标：
1. **数据归集与共享**
2. **核心业务数字化率**
3. **应用场景使用活跃度**
4. **区县治理中心"八大板块"应用和镇街"141"应用贯通覆盖率**
5. **区县治理中心实战活跃度**
6. **镇街乡治理中心实战活跃度**
7. **"9＋2"中心城区一体化实战活跃度**
8. **企事业单位核心业务数字化率**

#### 2025年底核心业务数字化率目标：
| 单位类型 | 数字化率目标 |
|---------|------------|
| 部门 | >90% |
| 区县 | >80% |
| 镇街 | >95% |
| 国企 | >95% |
| 高校 | >90% |
| 医院 | >90% |
| 金融机构 | >95% |

**工作方法**：
- 锚定"三年形成基本能力"目标
- 开展分级分类分层评价
- 各级各部门互学互促、比学赶超
- 推动基本能力建设走深走实

- **背景**：深入贯彻总书记视察重庆重要讲话重要指示精神
- **体制机制**：健全"大综合一体化"城市综合治理体制机制
- **策略**：突出中心城区先行先试、探路领跑
- **目标**：全力推动数字重庆基本能力建设实现突破性进展

### 三级治理中心实战能力形成
- **时间**：2024年7月-2025年4月
- **成效**：已闭环处置多跨事件超2700万件
- **能力**：具备事件中心、任务编排、智能分拨等中台能力

## 关键数据与成就（截至2025年6月）

### 平台建设
- **感知设备**：已纳管视频桩、传感器等大量设备（具体数据见IRS资源目录）
- **算力支撑**："疆算入渝"工程实施，在疆布局算力
- **数据汇聚**：基础数据库、主题数据库、专题数据库持续完善

### 三级治理中心
- **事件处置**：已闭环处置多跨事件超2700万件
- **能力提升**：具备事件中心、任务编排、智能分拨等中台能力

### 基层智治
- **镇街数量**：全市1031个镇街
- **网格规模**：设置6.2万个网格
- **网格员队伍**：配备专兼职网格员12.1万名
- **矛盾化解**：累计排查矛盾纠纷246.6万件，98.2%在基层化解

### AI+应用（人工智能+数字重庆）
- **城市治理大模型**：基于一体化平台海量数据和实战数据训练
- **典型应用**：智汇山城（金融消保）、校园餐AI监管、巴蜀文旅等

## 最新工作要求（2025版）

### 对高校的特殊要求
**核心业务梳理**：
- 学科建设
- 科研攻关
- 产学研合作
- 人才培养

**数字化率评价指标（最新迭代）**：
```
高校核心业务数字化率 =
  (高校业务事项编目数 ÷ 本行业业务事项编目平均数) × 10%
  + (高校已数字化的业务事项数 ÷ 高校业务事项编目数) × 90%
```

**工作建议**：
1. 全面细化梳理核心业务
2. 鼓励迭代原有旧系统，确有必要再谋划建设新应用
3. 加强与市教委、市科技局、市人力社保局、市公安局等部门对接
4. 将梳理出的业务事项关联至市级部门相关应用

### 对各单位的普遍要求
1. **核心业务梳理不能"走形式"**：聚焦落实党的二十大精神、解决主要矛盾
2. **避免"碎片化"**：解决本部门本领域最重要、最现实、最迫切的业务需求
3. **应用与业务强关联**：体现多跨，从群众需求出发，细化事项颗粒度
4. **全量数据归集**：应归集尽归集、能共享尽共享
