# 员工管理界面重设计

**日期**: 2026-03-26
**状态**: 待实现

## 背景

当前员工管理页面的数字员工展示不够"像人"，用户希望重新设计，让界面更像真实的团队成员。

## 设计目标

将员工列表从当前的"大卡片网格"改为"温暖卡片列表"风格，结合：
- **现代企业通讯录**的专业简洁
- **温暖人性化**的社交平台风格

## 核心决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 头像样式 | 圆头像+首字母+状态指示 | 简洁高效，后续可无缝支持上传真实照片 |
| 列表布局 | 温暖卡片列表 | 有呼吸感，头像更大，有温度 |
| 状态展示 | 状态点+活跃时间 | 有温度，用户熟悉，能感受到同事存在 |
| 描述内容 | 优先description，无则自动生成 | 有人情味，兼顾两种情况 |
| 点击交互 | 直接进入详情页 | 标准交互，简单直接 |
| 部门标签 | 彩色药丸 | 增强归属感，快速识别 |

## 设计规格

### 页面布局

- **左侧**：组织树保持不变
- **右侧**：员工列表改为紧凑的卡片列表

### 单个卡片结构

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   ┌────┐                                                │
│   │ 李 │  李明辉  [产品部]                               │
│   │    │  ● 刚刚活跃                                    │
│   └────┘  负责智能客服应答                    [编辑][删除]│
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 元素规格

| 元素 | 规格 |
|------|------|
| 卡片容器 | 白色背景，圆角12px，内边距14px 16px，底部间距10px |
| 头像 | 48px圆形，渐变色背景+首字(18px粗体白色)，在线时右下角12px绿点 |
| 名字 | 15px粗体(#0f172a) |
| 部门标签 | 10px字体，彩色药丸样式，内边距2px 8px，圆角10px |
| 状态行 | 12px字体，状态点6px + 时间文字 |
| 描述 | 13px(#64748b)，单行截断，上边距6px |

### 部门标签配色

| 部门 | 背景 | 文字 |
|------|------|------|
| 产品部 | #eef2ff | #6366f1 |
| 运营部 | #fff7ed | #ea580c |
| 技术部 | #f0fdfa | #0d9488 |
| 市场部 | #fdf2f8 | #db2777 |
| 其他 | 按名称哈希分配柔和色 | 对应深色 |

### 状态时间显示逻辑

基于员工最新运行记录计算：

| 时间差 | 显示 | 颜色 |
|--------|------|------|
| ≤5分钟 | 刚刚活跃 | #22c55e (绿) |
| ≤1小时 | X分钟前 | #eab308 (黄) |
| 今天 | 今天 HH:mm | #94a3b8 (灰) |
| 昨天 | 昨天 | #94a3b8 (灰) |
| 更早 | 离线 | #94a3b8 (灰) |

状态点颜色与文字颜色一致。

### 描述文字逻辑

1. 如果员工有 `description` 字段且非空 → 显示设置的内容
2. 否则，如果有运行记录 → 显示"今日处理了 X 个任务"
3. 否则 → 显示"等待分配工作"

### 交互设计

| 操作 | 行为 |
|------|------|
| 点击卡片 | 跳转员工工作台详情页 |
| 悬停卡片 | 卡片微微上浮，阴影增强；右侧浮现编辑/删除图标按钮 |
| 点击编辑 | 打开编辑侧边栏 |
| 点击删除 | 弹出确认对话框 |

### 悬停效果

- 卡片：`transform: translateY(-2px)`，阴影增强
- 操作按钮：默认透明，悬停时淡入显示

## 技术实现要点

### 修改文件

- `packages/nextclaw-digital-employee/app/pages/employees/index.vue`

### 主要改动

1. **移除**：当前的证件照风格头像SVG生成代码
2. **简化**：头像改为圆形渐变背景+首字
3. **重构**：卡片HTML结构，从大卡片改为紧凑列表卡片
4. **更新**：CSS样式，适配新的卡片设计
5. **新增**：活跃时间计算函数（基于latestRun）
6. **新增**：部门颜色映射函数

### 数据依赖

已有数据可满足需求：
- `emp.name` - 名字/首字
- `emp.code` - 编码
- `emp.description` - 描述
- `emp.departmentId` - 部门ID（用于获取部门名称和颜色）
- `emp.latestRun` - 最新运行记录（用于计算活跃状态）
- `emp.skills` - 技能列表（用于统计技能数）
