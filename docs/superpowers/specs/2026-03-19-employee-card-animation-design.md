# 数字员工卡片动画设计

**日期**: 2026-03-20
**状态**: 设计确认
**影响文件**: `app/pages/employees/index.vue`

## 背景

数字员工中心的员工卡片目前使用渐变 banner + 像素头像的静态设计，缺乏"员工正在工作"的生动感。用户希望让卡片更有生命力，更像团队成员。

## 设计目标

1. **生动感** — 通过动画展示员工"正在工作"的状态
2. **写实风格** — 彩色人物 + 真实办公环境，避免动漫感
3. **公司氛围** — 灰白办公格调，类似真实企业环境
4. **信息结构不变** — 保持现有字段展示

## 设计方案

### 顶部场景区域

将原有渐变 banner 替换为办公工作场景，高度调整为 100px。

#### 场景构成

```
┌─────────────────────────────────────┐
│  天花板灯带                          │
│  ┌──────────────────────────────┐   │
│  │ 隔断墙      办公区      隔断墙 │   │
│  │  🪴    ┌─────────┐     🌿   │   │
│  │        │ 显示器  │          │   │
│  │        │ +支架   │          │   │
│  │     🧑‍💼  ← 彩色人物          │   │
│  │     ──────                        │
│  │     键盘      鼠标               │   │
│  └──────────────────────────────┘   │
│           桌面 (灰色)                │
└─────────────────────────────────────┘
```

#### 场景元素

| 元素 | 样式 | 说明 |
|------|------|------|
| 背景 | 灰白渐变 `#f1f5f9 → #e2e8f0 → #cbd5e1` | 公司办公环境 |
| 隔断墙 | 左右两侧灰色区域 | 增加空间感 |
| 天花板灯带 | 顶部淡黄色光带 | 办公室光照感 |
| 植物 | 左侧🪴 + 右侧🌿 | 点缀装饰 |
| 桌面 | 深灰渐变 `#9e9e9e → #757575` | 办公桌面 |
| 显示器 | 深灰边框 + 白色屏幕 | 显示文档界面 |
| 人物 | 肤色 + 棕发 + 蓝衬衫 | 写实彩色风格 |

#### 显示器内容

展示文档编辑界面：
- 顶部红黄绿按钮（macOS 风格）
- 文档标题行（蓝色）
- 文字内容行（灰色）
- 闪烁光标

#### 人物构成

- **头部**: 肤色 `#fcd9b6`，圆角方形
- **头发**: 棕色 `#4a3728`，覆盖头顶
- **身体**: 蓝色衬衫 `#3b82f6`
- **手臂**: 肤色，左右交替打字动画

### 动画清单

| 元素 | 动画 | 时长 | 效果 |
|------|------|------|------|
| 人物整体 | 浮动 | 3s | 轻微上下浮动 |
| 头部 | 晃动 | 4s | 随打字轻微晃动 |
| 左手臂 | 敲键盘 | 0.6s | 旋转敲击 |
| 右手臂 | 敲键盘 | 0.6s | 旋转敲击（延迟0.3s） |
| 显示器 | 光晕脉冲 | 3s | 屏幕边缘发光 |
| 光标 | 闪烁 | 1s | 文档光标闪烁 |
| 植物 | 摇摆 | 4s | 轻微左右摇摆 |

### CSS 动画定义

```css
/* 人物浮动 */
@keyframes subtle-float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-2px); }
}

/* 头部晃动 */
@keyframes head-move {
  0%, 100% { transform: rotate(0deg); }
  30% { transform: rotate(2deg); }
  70% { transform: rotate(-2deg); }
}

/* 左手臂敲键盘 */
@keyframes arm-type-left {
  0%, 100% { transform: rotate(0deg); }
  30% { transform: rotate(-15deg); }
  60% { transform: rotate(-5deg); }
}

/* 右手臂敲键盘 */
@keyframes arm-type-right {
  0%, 100% { transform: rotate(0deg); }
  30% { transform: rotate(5deg); }
  60% { transform: rotate(15deg); }
}

/* 显示器光晕 */
@keyframes screen-glow {
  0%, 100% { box-shadow: 0 0 15px rgba(59, 130, 246, 0.15); }
  50% { box-shadow: 0 0 25px rgba(59, 130, 246, 0.25); }
}

/* 光标闪烁 */
@keyframes cursor-blink {
  0%, 50% { opacity: 1; }
  51%, 100% { opacity: 0; }
}

/* 植物摇摆 */
@keyframes plant-sway {
  0%, 100% { transform: rotate(-2deg); }
  50% { transform: rotate(2deg); }
}
```

### 配色方案

保持现有的 `AVATAR_PALETTES` 配色系统，用于生成每个员工独特的头像配色。

场景配色固定为公司办公风格：
- 背景: 灰白系
- 桌面: 深灰系
- 人物: 肤色 + 蓝衬衫（可根据员工姓名生成不同衬衫颜色）

## 实现要点

1. **纯 CSS 动画**: 使用 `transform` 和 `opacity`，避免触发重绘
2. **场景高度**: 100px，确保头像不被遮挡
3. **人物配色**: 可考虑根据员工姓名哈希生成不同衬衫颜色
4. **性能优化**: 动画属性使用 GPU 加速
