# v0.15.68-job-run-access-and-creator-visibility

## 迭代完成说明

- 为数字员工新增两项可配置权限：查看全部定时任务、查看全部运行记录，并接入安全中心权限管理。
- 定时任务列表改为按角色权限返回 `all/own` 访问范围；非全量权限用户仅可查看、编辑、删除、立即执行自己创建的任务。
- 运行记录新增 `created_by_user_id` 归因字段，手动聊天和定时任务触发的执行会写入发起用户；运行记录列表与详情按权限过滤。
- 定时任务页新增创建人展示；运行记录页新增发起人展示；安全中心会自动展示新增权限项。

## 发布/部署方式

- 在 `packages/nextclaw-digital-employee` 下执行数据库迁移：`pnpm migrate:latest`。
- 按常规流程发布数字员工服务，确保新后端代码与数据库字段同时上线。
- 上线后使用管理员账号检查安全中心权限项是否可见，再使用普通账号验证 own 范围是否生效。

## 用户/产品视角的验收步骤

1. 管理员进入安全中心-权限管理，确认可看到“查看全部定时任务”“查看全部运行记录”两个权限开关。
2. 用普通角色账号登录，关闭上述两个权限后进入某个数字员工页面，确认只能看到自己创建的定时任务和自己发起的运行记录。
3. 用同一普通角色尝试直接编辑、删除或立即执行其他人创建的任务，确认接口拒绝访问。
4. 再开启相应权限，刷新页面后确认可以查看全部任务/运行记录，并能看到每条记录的创建人或发起人。
