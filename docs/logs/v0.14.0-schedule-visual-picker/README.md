#### 2.2 / 2.3 可视化时间选择器（按时间表）  
在"按时间表"运行方式下提供两种配置方式，通过选项卡切换：

| 模式 | 描述 |
|------|------|
| **可视化配置** | 下拉选择重复类型 + 日期/星期/日期号选择器 + 时间选择器，系统自动生成 Cron |
| **Cron 表达式** | 直接填写原始 Cron，附带常见示例提示 |

可视化时间选择支持四种重复类型（对应截图设计）：

| 重复类型 | 显示字段 | 生成示例 |
|----------|----------|----------|
| **不重复** | 日期选择器（年/月/日，最早=今天）+ 时间 | `0 9 24 3 *` |
| **每天** | 时间 | `0 9 * * *` |
| **每周** | 星期选择（周一..周日）+ 时间 | `0 9 * * 1` |
| **每月** | 几号（1日..31日）+ 时间 | `0 9 1 * *` |

**Cron 双向映射逻辑（`loadVisualFromCron`）**  
编辑已有任务时自动解析 cronExpr 并回显到可视化选择器：
- `* * * * *` 且 dow=`*`、dom=`*` → 每天
- dow 为单个数字 → 每周
- dom 非 `*` 且 month 非 `*` → 不重复（含年份前缀）
- dom 非 `*` 且 month=`*` → 每月
- **非标准 cron**（如 `1-5` 工作日区间）→ 自动切换到 Cron 表达式模式

**任务卡片展示优化**  
- `cronHumanLabel` 将 cron 转为可读文本：`每天 09:00`、`每周周一 09:00`、`每月1日 09:00`、`3月24日 09:00（不重复）`
- `everyMsHumanLabel` 输出 `每 X 小时 Y 分钟` 组合格式

#### 2.4 固定间隔输入优化  
毫秒输入框改为小时 + 分钟 两个数值输入框，自动换算为 ms（最短 1 分钟），去掉"毫秒=？ms"的心智负担

**功能验收步骤**：
1. 打开任意员工"工作台"→"概述" tab，确认"自动任务"和"最近结果"卡片不再显示

5. 切换到"Cron 表达式"模式→可直接编辑
6. 运行方式选"固定间隔"→显示小时 + 分钟 输入框
7. 编辑一条已有 cron 任务，确认选择器正确回显（每天/每周/每月/不重复）
8. 保存后，任务卡片显示可读文本（如"每天 09:00"）而非原始 cron
