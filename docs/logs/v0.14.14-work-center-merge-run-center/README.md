# v0.14.14 — 工作中心合并运行中心，大屏看板全面优化

## 迭代完成说明

### 改了什么

1. **工作中心（`/dashboard`）全面升级为平台大屏看板**
   - 副标题由"运行态势与待处理事项"改为**"平台运行全景"**，描述更新为"汇聚数字员工运行态势、异常预警、执行记录与系统数据统计，一屏掌控全局"
   - 新增**执行统计模块**（双列布局右侧）：显示总运行量、自动任务数、待处理失败三个核心指标卡片
   - 将原"最近执行（仅摘要卡片）"替换为**完整的运行记录全表**：
     - 支持状态筛选（全部 / 已完成 / 执行中 / 失败）
     - 分页器（上一页 / 页码 / 下一页）
     - 点击"详情"按钮弹出侧滑详情面板（含触发方式、状态、事件数、结果摘要、关键事件 timeline、原始结果折叠）
     - 与原运行中心功能 100% 等价，无功能降级

2. **去掉独立"运行中心"导航项**
   - `app/layouts/default.vue` 中移除了 `{ label: "运行中心", to: "/runs", icon: Clock }` 导航项及 `Clock` 图标导入
   - 导航栏剩余 5 项：组织架构 / 工作中心 / 技能中心 / 集成中心 / 安全中心

3. **`/runs` 路由自动重定向**
   - `app/pages/runs/index.vue` 改为透明重定向页面（`navigateTo("/dashboard", { replace: true })`），保证历史链接/书签不中断

- 仅前端变更（Vue SFC），无后端/数据库改动
- 按标准前端发布流程：`/release-frontend`
- migration：**不适用**（无数据库变更）

## 用户/产品视角的验收步骤

1. 登录平台，确认左侧导航中**没有"运行中心"**菜单项
2. 点击**"工作中心"**，确认页面副标题为"平台运行全景"，并能看到四个统计卡 + 预警区 + 即将运行员工 + 执行统计卡 + 完整的全量运行记录表格
3. 在运行记录表格中筛选"失败"，确认仅显示失败记录
4. 点击任意一条记录的"详情"，确认滑出面板包含结果摘要和事件追踪
5. 在浏览器地址栏直接输入 `/runs`，确认自动跳转至工作中心，不出现 404 或空白页
