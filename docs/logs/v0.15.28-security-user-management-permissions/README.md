## 用户/产品视角的验收步骤

1. 使用管理员账号登录系统并进入“安全中心”。
2. 切换到“权限管理”页签，选择“超级管理员”等角色。
3. 确认权限详情中新增“用户管理”分组。
4. 确认分组内能看到“查看用户列表”“创建本地用户”“编辑用户信息与角色”“重置本地用户密码”“同步外部用户”“删除用户”等权限项。
5. 确认超级管理员角色因具备 `user:*`，上述权限项均显示为已授权状态。
