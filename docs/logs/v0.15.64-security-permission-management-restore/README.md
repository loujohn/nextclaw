## 用户/产品视角的验收步骤

1. 登录数字员工平台并进入“安全中心 - 权限管理”。
2. 确认页面顶部能看到“真实可配置权限”和“历史权限目录”两组概览卡片。
3. 在左侧切换不同角色，确认上半部分仍可查看并切换已接入的真实权限。
4. 在搜索框输入关键字，确认真实权限列表与历史权限目录都会同步过滤。
5. 向下查看“历史权限目录”，确认此前权限内容仍完整保留展示，没有被新权限接线覆盖。
