# v0.15.27-user-management-permission-notice

## 迭代完成说明

- 调整用户管理页权限态：当前登录用户不是管理员时，不再继续请求 `/api/users`，避免页面进入 403 报错链路。
- 为无权限用户增加正常业务提示：页面展示“当前账号暂无用户管理权限，请联系管理员开通权限”，并在首次进入时给出一次 info toast 提醒。
- 侧边导航与移动端底部导航同步隐藏非管理员的“用户管理”入口，减少误入后触发无效请求。

## 测试/验证/验收方式

- 结果说明：本次改动无新的 ESLint error；当前仍存在 `app/pages/users/index.vue` 的既有 `max-lines` warning（文件总行数 842，阈值 800），属于存量告警，不是本次改动引入。
- 不适用项：未执行 `build` / `tsc`，本次只调整前端权限态与导航显示，先按影响范围执行最小充分验证。

- 按现有前端/数字员工服务发布流程部署 `packages/nextclaw-digital-employee`。

## 用户/产品视角的验收步骤

1. 使用普通用户账号登录系统。
2. 确认导航中不再出现“用户管理”入口；如果直接访问 `/users`，页面应显示无权限提示，而不是接口报错堆栈。
3. 使用管理员账号登录系统。
4. 确认管理员仍能看到“用户管理”入口，并能正常加载用户列表。
5. 观察浏览器网络请求，普通用户访问 `/users` 时不应再发起 `/api/users?page=1&pageSize=10` 请求。
