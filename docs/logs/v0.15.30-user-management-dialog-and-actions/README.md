# v0.15.30-user-management-dialog-and-actions

## 迭代完成说明

- 用户管理页删除操作从浏览器原生确认框切换为项目统一的 SharedConfirmDialog，交互样式与系统弹窗保持一致。
- 用户列表移除了“同步资料”独立列，改为在“操作”列中为外部同步用户提供图标按钮，减少表格横向占用。
- 将“来源”中的登录方式信息拆分成独立列显示，列表信息层次更清晰。
- 为启用/禁用操作增加统一的二次确认弹窗，并在操作成功后按启用或禁用结果给出提示。

## 用户/产品视角的验收步骤

1. 使用管理员账号进入用户管理页面，确认列表中不再出现“同步资料”列，且“来源”和“登录方式”分别独立展示。
2. 找到一条外部同步用户记录，确认“操作”列出现同步资料图标按钮，点击后能打开同步资料详情弹窗。
3. 点击任意非当前用户的“删除”按钮，确认打开的是系统统一确认弹窗，而不是浏览器原生提示框。
4. 点击任意用户的“启用”或“禁用”状态按钮，确认先弹出统一确认弹窗；确认后状态更新，并出现成功提示。
5. 完成删除或启停后，确认列表数据与提示文案符合实际操作结果。
