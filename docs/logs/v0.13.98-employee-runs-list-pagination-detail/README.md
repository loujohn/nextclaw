# v0.13.98 - 员工运行记录列表化 + 分页 + 详情弹窗

## 迭代完成说明（改了什么）
- 将员工详情页的“运行记录”模块从可点击卡片改为直接列表展示（表格行）。
- 新增“详情”按钮：每条记录可独立打开详情弹窗（Slide-over），查看触发方式、状态、事件、结果摘要与原始结果。
- 员工运行记录改为分页查询：前后端统一支持 `page` 和 `pageSize`，页面固定 `pageSize=10`。
- 后端新增仓储方法 `listPagedByEmployeeId`，避免员工运行记录接口一次性返回全部数据。
- 员工运行记录接口改为返回分页结构：`items`、`total`、`page`、`pageSize`，并复用运行中心列表的展示模型。
