# v0.13.65 employee-ui-view-toast-card-actions

## 迭代完成说明

### 1. 编辑页面风格与新增对齐
- 编辑（Editor）Slide-over 面板重构为与新增（Creator）完全一致的 **4 步分步向导**结构：
  - Step 1：基础信息（名称、编码只读、职责描述、角色设定）
  - Step 2：工作设定（模型、服务对象、心跳内容、启动任务、操作规则）
  - Step 3：能力配置（技能多选，含分类标签）
  - Step 4：自动任务（调度类型、Cron/间隔输入）
- 步骤导航、样式、提示文案与新增保持一致。

### 2. 新增查看（Viewer）功能
- 新增只读查看 Slide-over 面板，风格与新增/编辑完全一致的 4 步分步 Tab 导航。
- 所有字段以圆角浅灰文本块展示，不可编辑。
- **查看面板中去掉上一步/下一步按钮**，Tab 标签可自由点击切换步骤，底部仅保留「关闭」按钮。

### 3. 编辑/删除成功或失败时添加 Toast 系统提示
- 在**页面正上方居中**显示浮动 Toast 通知（`fixed top-0 inset-x-0`），成功绿色图标，失败红色图标。
- 3.5 秒自动消失，支持手动关闭。
- 编辑保存成功 → 「员工信息已保存」；失败 → 「保存失败：…」
- 删除成功 → 「已删除员工『xxx』」；失败 → 「删除失败：…」
- Toast 进出使用 `TransitionGroup name="toast"` 动画（上滑淡入/淡出）。

### 4. 新增/编辑/删除按钮改为 hover 隐藏式
- 卡片底部原「编辑/删除」按钮行整体移除。
- 改为鼠标悬停卡片时才显示的三个图标按钮（查看 Eye、编辑 Pencil、删除 Trash2），使用 `opacity-0 group-hover:opacity-100 transition-all` 实现。
- 「进入」链接保留在右侧，布局更简洁。
- 调度信息与操作图标同行，合理利用底部空间。

## 测试/验证方式

```bash
# 编译验证（已通过）
pnpm --filter @nextclaw/digital-employee build
# 输出: ✨ Build complete! 无报错
```

冒烟步骤（dev 模式）：
1. `pnpm --filter @nextclaw/digital-employee dev`，访问 `http://localhost:3001/employees`
2. 鼠标悬停到员工卡片，确认查看/编辑/删除图标出现（opacity 过渡）
3. 点击「查看」图标 → 查看面板弹出，仅显示「关闭」按钮，Tab 可自由切换
4. 点击「编辑」图标 → 编辑面板弹出，4 步分步，可逐步导航保存
5. 保存/删除后，页面顶部正中出现 Toast，3.5 秒消失

## 发布/部署方式

纯前端改动，无后端/数据库变更：
- `build/lint/tsc` 适用（已通过 build 验证）
- Migration：不适用（无数据库变更）
- 部署：执行前端构建并重新启动 digital-employee 服务即可

## 用户/产品视角的验收步骤

1. **交互便捷性**：员工卡片视觉更简洁，操作图标仅在悬停时显现，卡片主体信息不被按钮占用。
2. **查看功能**：可通过「查看」图标快速浏览员工完整配置，Tab 自由切换4个维度，无需步进导航。
3. **编辑一致性**：编辑面板与新增面板体验完全一致，减少学习成本。
4. **操作反馈**：保存/删除后页面顶部立即出现提示横幅（顶部居中，最显眼位置），成功/失败状态一目了然。
