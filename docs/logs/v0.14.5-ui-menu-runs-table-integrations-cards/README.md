# v0.14.5 · 菜单顺序调整 / 运行中心表格化 / 集成中心扩展卡片

## 迭代完成说明

本次迭代包含四项 UI 调整，均在 `packages/nextclaw-digital-employee` 前端层完成，不涉及后端 API 或数据库变更。

### 1. 菜单"工作台"与"员工中心"互换位置

- 文件：`app/layouts/default.vue`
- `navItems` 数组中将"员工中心"调整到第一位，"工作台"调整到第二位，使员工管理作为首要入口展现。

### 2. 屏蔽"员工中心"中的"所有员工（全部员工）"模块

- 文件：`app/components/DepartmentTree.vue`
- 移除了侧边栏组织树中"全部员工"入口按钮，保留"总览"及各部门节点。
- 如后续需恢复，在注释位置 `<!-- 全部员工（已屏蔽） -->` 下方重新添加对应 `<button>` 即可。

### 3. 运行中心卡片列表改为 table 列表

- 文件：`app/pages/runs/index.vue`
- 原卡片网格（`grid gap-4 sm:grid-cols-2`）替换为标准 HTML `<table>`，列定义：员工 / 状态 / 触发方式 / 摘要 / 开始时间 / 详情操作。
- 保留原有 loading、empty-state、分页、详情 slide-over 逻辑不变。
- 摘要列使用纯文本 truncate 展示，避免 v-html 在表格单元格内排版问题。

### 4. 集成中心新增"政务公司知识库"与"代码仓库"展示卡片

- 文件：`app/pages/integrations/index.vue`
- 在现有动态卡片网格末尾追加两张静态卡片，风格与 API 卡片完全一致（tone=slate）。
- 图标：`BookOpen`（政务公司知识库）、`GitBranch`（代码仓库），均来自 `lucide-vue-next`。
- 状态标签："暂未接入"，操作按钮："即将上线"（disabled），无任何点击逻辑。

## 用户 / 产品视角验收步骤

1. 打开数字员工平台，确认侧边导航第一项为**员工中心**，第二项为**工作台**。
2. 进入**员工中心**，左侧组织架构树中仅显示"总览"和各部门节点，不显示"全部员工"入口。
3. 进入**运行中心**，运行记录以表格形式显示（含表头行：员工/状态/触发方式/摘要/开始时间），点击"详情"可打开侧滑板。
4. 进入**集成中心**，卡片列表末尾可见"政务公司知识库"和"代码仓库"两张卡片，样式统一，按钮显示"即将上线"且不可点击。
