## 用户 / 产品视角的验收步骤

1. 打开员工中心，点击任意部门进入员工列表。
2. 选择一个员工进入工作台。
3. 点击顶部“员工中心”返回入口，确认回到刚才的员工列表，而不是组织架构总览。
4. 在工作台切到“聊天”，确认页面只展示对话区、消息流和输入框。
