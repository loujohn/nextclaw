# v0.15.5 digital employee chat upload files workspace preview

## 迭代完成说明

本次完成了数字员工聊天上传文件与工作空间预览主链路：

1. 聊天页新增多文件上传、待发送附件列表、发送前移除能力。
2. 新增上传接口，将文件落盘到员工工作空间的 `uploadFile/YYYY-MM-DD/` 目录。
3. 聊天发送接口支持携带附件引用；用户消息 metadata 持久化附件快照，并把文件路径上下文拼装进发送给智能体的文本。
4. 会话历史回放与聊天实时页统一支持渲染用户消息附件，并可跳转到工作空间对应上传文件。
5. 工作空间接口扩展为返回 `核心文件 + 上传文件树`，并新增上传文件详情与原始文件流接口。
6. 工作空间页改为双分组结构，支持按年月日展开上传文件树、默认选中上传附件、展示来源会话/来源消息/发送文本，并对上传文件提供只读预览与下载。
7. 保持达梦数据库零 schema 变更，继续复用 `chat_messages.metadata_json` 保存附件快照。

## 用户 / 产品视角的验收步骤

1. 进入任一数字员工聊天页，点击“上传文件”，选择 `txt/md/pdf/docx/xlsx/pptx/图片` 中的任意文件。
2. 确认输入区下方出现待发送附件列表，并可在发送前删除单个附件。
3. 输入文本后发送，确认用户消息气泡下出现附件列表。
4. 刷新页面或切换会话后返回，确认历史消息仍能展示同一批附件。
5. 点击任一附件，确认跳转到工作空间页并默认展开“上传文件”，选中对应文件。
6. 在工作空间中确认：
   - 左侧可见“核心文件”和“上传文件”双分组
   - 上传文件按年 / 月 / 日展开
   - 右侧展示来源会话、来源消息、发送文本
   - 文本 / Markdown / 图片 / PDF 可预览
   - 上传文件不可编辑，但可以下载
