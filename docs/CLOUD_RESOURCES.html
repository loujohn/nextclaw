一、系统模块

1.1 核心模块

模块 说明 资源消耗
Nuxt Server Web 应用 + API 服务 CPU + 内存
AgentEngine 池 多智能体执行引擎 内存 (主要)
ChannelManager 多渠道消息管理 网络 + 内存
CronService 定时任务调度 CPU (低)
SessionManager 会话状态管理 内存 + 存储
SkillsLoader 技能加载与执行 内存 + CPU

1.2 数据存储模块

模块 说明 存储类型
PostgreSQL 业务数据持久化 关系型数据库
Redis 会话缓存 + 消息队列 内存数据库
文件存储 会话文件 + 技能包 本地磁盘/对象存储

1.3 外部依赖

依赖 用途
LLM API AI 模型调用 (OpenAI/Claude/DeepSeek 等)
钉钉 API 消息推送、组织架构同步
飞书 API 消息推送
其他渠道 API 企业微信、Slack 等

三、服务器资源需求

3.1 推荐配置 (支持 20-50 个智能体)

应用服务器
CPU16 vCPU
内存32 GB
系统盘50 GB SSD
数据盘300 GB SSD
带宽20-50 Mbps

3.2 最小配置 (支持 5-10 个智能体)

应用服务器
CPU4 vCPU
内存16 GB
存储100 GB SSD
带宽10 Mbps

3.3 智能体数量与资源对照表

智能体数量 CPU 内存 存储
5-10 个 4 vCPU 16 GB 100 GB
10-20 个 8 vCPU 24 GB 200 GB
20-50 个 16 vCPU 32 GB 300 GB
50-100 个 32 vCPU 64 GB 500 GB

3.4 内存分配详解

支持多智能体的关键在于内存配置，每个 Agent 实例约占用 300-500 MB 内存。

四、数据库资源需求

4.1 PostgreSQL

配置项 推荐配置 说明
CPU 4 vCPU 查询处理
内存 8 GB 连接池 + 查询缓存
存储 200 GB SSD 业务数据
连接数 100-200 应用连接池

数据表清单：

表名 用途
departments部门信息
employees数字员工
human_employees人类员工 (钉钉同步)
employee_skills员工技能配置
employee_schedules调度配置
skill_installations技能安装记录
integration_connections集成配置
run_records运行记录 (高频写入)
run_events运行事件 (高频写入)
org_sync_config组织同步配置

4.2 Redis

配置项 推荐配置 说明
内存 4-8 GB 会话缓存 + 消息队列
持久化 AOF 数据安全

用途：

  • 会话状态缓存
  • 消息队列 (Agent 通信)
  • 分布式锁 (可选)

4.3 文件存储

存储类型 容量 内容
会话文件 50-100 GB JSONL 对话历史
技能包 10-50 GB 安装的技能文件
日志 20-50 GB 应用日志
备份 50-100 GB 数据库备份

五、网络资源需求

资源 配置 说明
公网带宽 20-50 Mbps API 请求 + 消息推送
内网带宽 不限 数据库/Redis 通信
并发连接 200-500 同时在线用户
