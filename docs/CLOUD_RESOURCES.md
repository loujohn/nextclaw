# NextClaw 数字员工平台 - 云资源需求规划

> 文档版本: 2.2
> 更新日期: 2026-03-24
> 项目: packages/nextclaw-digital-employee

---

## 一、系统模块

### 1.1 核心模块

| 模块 | 说明 | 资源消耗 |
|-----|------|---------|
| **Nuxt Server** | Web 应用 + API 服务 | CPU + 内存 |
| **AgentEngine 池** | 多智能体执行引擎 | 内存 (主要) |
| **ChannelManager** | 多渠道消息管理 | 网络 + 内存 |
| **CronService** | 定时任务调度 | CPU (低) |
| **SessionManager** | 会话状态管理 | 内存 + 存储 |
| **SkillsLoader** | 技能加载与执行 | 内存 + CPU |

### 1.2 数据存储模块

| 模块 | 说明 | 存储类型 |
|-----|------|---------|
| **PostgreSQL** | 业务数据持久化 | 关系型数据库 |
| **Redis** | 会话缓存 + 消息队列 | 内存数据库 |
| **文件存储** | 会话文件 + 技能包 | 本地磁盘/对象存储 |

### 1.3 外部依赖

| 依赖 | 用途 |
|-----|------|
| LLM API | AI 模型调用 (OpenAI/Claude/DeepSeek 等) |
| 钉钉 API | 消息推送、组织架构同步 |
| 飞书 API | 消息推送 |
| 其他渠道 API | 企业微信、Slack 等 |

## 二、服务器资源需求

### 2.1 推荐配置 (支持 20-50 个智能体)

| 资源 | 配置 | 说明 |
|-----|------|------|
| **CPU** | 8-16 vCPU | 对话处理、SSR 渲染 |
| **内存** | 32 GB | Agent 引擎池 + 会话缓存 |
| **系统盘** | 50 GB SSD | 操作系统 + 应用 |
| **数据盘** | 200-500 GB SSD | 会话文件 + 技能 + 日志 |
| **带宽** | 20-50 Mbps | API 请求 + 消息推送 |

### 2.2 最小配置 (支持 5-10 个智能体)

| 资源 | 配置 | 说明 |
|-----|------|------|
| **CPU** | 4 vCPU | 基本对话处理 |
| **内存** | 16 GB | 有限的 Agent 实例 |
| **存储** | 100 GB SSD | 基础存储需求 |
| **带宽** | 10 Mbps | 低并发场景 |

### 2.3 内存分配详解

支持多智能体的关键在于内存配置：

```
┌────────────────────────────────────────────────────────────────┐
│ 32 GB 内存分配 (推荐配置)                                        │
├────────────────────┬───────────────────────────────────────────┤
│ 系统预留           │ 2 GB                                     │
│ Nuxt 进程          │ 1-2 GB                                   │
│ AgentEngine 池     │ 16-20 GB (30-50个智能体实例)              │
│ SessionManager     │ 2-4 GB (会话缓存)                         │
│ SkillsLoader       │ 1-2 GB                                   │
│ 数据库连接         │ 1 GB                                     │
│ 缓冲区             │ 2-4 GB                                   │
└────────────────────┴───────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────────┐
│ 16 GB 内存分配 (最小配置)                                        │
├────────────────────┬───────────────────────────────────────────┤
│ 系统预留           │ 2 GB                                     │
│ Nuxt 进程          │ 1 GB                                     │
│ AgentEngine 池     │ 8-10 GB (5-10个智能体实例)                │
│ SessionManager     │ 1-2 GB                                   │
│ SkillsLoader       │ 0.5-1 GB                                 │
│ 数据库连接         │ 0.5 GB                                   │
└────────────────────┴───────────────────────────────────────────┘
```

### 2.4 智能体数量与资源对照

| 智能体数量 | CPU | 内存 | 存储 |
|-----------|-----|------|------|
| 5-10 个 | 4 vCPU | 16 GB | 100 GB |
| 10-20 个 | 8 vCPU | 24 GB | 200 GB |
| 20-50 个 | 16 vCPU | 32 GB | 300 GB |
| 50-100 个 | 32 vCPU | 64 GB | 500 GB |

## 三、数据库资源需求

### 3.1 PostgreSQL

| 配置项 | 推荐配置 | 说明 |
|-------|---------|------|
| **CPU** | 4 vCPU | 查询处理 |
| **内存** | 8 GB | 连接池 + 查询缓存 |
| **存储** | 200 GB SSD | 业务数据 |
| **连接数** | 100-200 | 应用连接池 |

**数据表**：
```
departments          # 部门信息
employees            # 数字员工
human_employees      # 人类员工 (钉钉同步)
employee_skills      # 员工技能配置
employee_schedules   # 调度配置
skill_installations  # 技能安装记录
integration_connections # 集成配置
run_records          # 运行记录 (高频写入)
run_events           # 运行事件 (高频写入)
org_sync_config      # 组织同步配置
```

### 3.2 Redis

| 配置项 | 推荐配置 | 说明 |
|-------|---------|------|
| **内存** | 4-8 GB | 会话缓存 + 消息队列 |
| **持久化** | AOF | 数据安全 |

**用途**：
- 会话状态缓存
- 消息队列 (Agent 通信)
- 分布式锁 (可选)

### 3.3 文件存储

| 存储类型 | 容量 | 内容 |
|---------|------|------|
| 会话文件 | 50-100 GB | JSONL 对话历史 |
| 技能包 | 10-50 GB | 安装的技能文件 |
| 日志 | 20-50 GB | 应用日志 |
| 备份 | 50-100 GB | 数据库备份 |
