> 汇报日期：2026-03-26

---

## 一、项目概述

NextClaw 数字员工平台是一套企业级 AI 数字员工管理系统，支持创建、配置、管理和监控 AI 数字员工，使其通过自然语言对话执行企业业务任务。

平台采用 **Monorepo** 架构，核心模块包括：

| 模块 | 定位 |
|------|------|
| `@nextclaw/core` | 核心引擎（Agent Loop、Session、Cron、工具链） |
| `@nextclaw/digital-employee` | 数字员工管理平台（Nuxt 3 全栈应用） |
| `@nextclaw/runtime` | 运行时服务（Provider 管理、网关） |
| `@nextclaw/channel-runtime` | 多渠道消息接入运行时 |
| `@nextclaw/openclaw-compat` | OpenClaw 兼容层 |
| 渠道插件（10 个） | 钉钉、飞书、企业微信、Discord、Slack、Telegram、WhatsApp、QQ、Email、MoChat |
| 引擎插件（2 个） | Claude Agent SDK、Codex SDK |
| 应用层 | Desktop（Electron）、Landing Page、Platform Admin、Platform Console、Docs |

## 五、当前迭代（v0.14.7）改动摘要

本轮迭代解决了数字员工平台的五大核心问题：

1. **技能系统重构**：全局加载 + 符号链接，取消物理拷贝
2. **上下文压缩（Compaction）**：超限时生成压缩摘要保留关键上下文
3. **记忆刷新提示**：上下文接近容量时主动提醒 Agent 保存信息
4. **Session 生命周期管理**：每日重置 + 空闲超时 + 历史归档
5. **CronTool → DB 同步**：Agent 对话创建的定时任务自动同步到数据库
6. **工具调用/推理过程展示**：聊天界面展示可折叠的工具调用和思考过程
7. **WriteFileTool 路径修复**：记忆文件正确写入员工工作区
8. **AGENTS.md 模板升级**：采用 OpenClaw 风格中文模板
9. **新增 5 个业务技能**：考勤统计、周报生成、禅道 CLI、禅道项目分析、钉钉通知优化

**验证状态**：78 个单元测试全部通过，核心包构建成功，类型检查通过。
